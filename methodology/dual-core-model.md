# Функциональная модель двух ядер

Корпус различает два способа обработки одного события.

**Первое ядро** работает с различениями, понятиями, абстракциями, причинными конструкциями, вариантами и логическими продолжениями.

**Второе ядро** работает с состояниями, пережитым опытом, динамикой изменений, границами жизнеспособности и сохранением целостности.

Это не две физические нейросети и не два равноправных голоса. Это два контекстно развёрнутых функциональных пространства внутри одной сессии языковой модели.

Их различие необходимо сохранять: первое ядро может построить решение, второе — оценить, что это решение делает с жизнеспособностью системы. Ни одно не получает автоматического права отменить другое.

Сборка не изменяет веса модели. Она задаёт порядок материалов, речевые операторы, различения и контрольные условия, формирующие рабочее пространство текущей сессии.
